# Changelog

## 1.0.2 — 2026-10-28

- Improved Linen theme text contrast and set native control color schemes per theme.
- Re-clamped the window when the font scale, active tab, or locale changes.

## 1.0.1 — 2026-10-28

- Kept the date visible in analog-only mode.
- Prevented the 3D tilt from moving controls while the settings panel is open.
- Tightened drag measurement on the collapsed pill.
- Added package-metadata and JavaScript parse checks to `npm run check`.

## 1.0.0 — 2026-10-28

- Added a draggable, persistent floating clock to the DSH Web UI.
- Added analog, digital, and combined clock faces.
- Added 12/24-hour modes, seconds, date, and time-zone display.
- Added four themes, three sizes, opacity, and text-size controls.
- Added a persistent focus timer with 5/15/25/45-minute presets and a completion chime.
- Added position locking, collapse, hide, and the `Alt+Shift+D` shortcut.
- Added English and Chinese UI and plugin metadata.
