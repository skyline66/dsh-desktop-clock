# Changelog

## 1.0.0 — 2026-10-28

- Added a draggable, persistent floating clock to the DSH Web UI.
- Added analog, digital, and combined clock faces.
- Added 12/24-hour modes, seconds, date, and time-zone display.
- Added four themes, three sizes, opacity, and text-size controls.
- Added a persistent focus timer with 5/15/25/45-minute presets and a completion chime.
- Added position locking, collapse, hide, and the `Alt+Shift+D` shortcut.
- Added English and Chinese UI and plugin metadata.
